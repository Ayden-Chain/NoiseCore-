# Noisecore

Static music e-commerce site (HTML, CSS, vanilla JS). No build step.

- `index.html` – all pages (Home, Products, About, Deals, Membership) switched by URL hash
- `style.css` – styles, light/dark theme
- `script.js` – products, cart, filters, form validation, hero animation

Run locally: open `index.html`, or `npx serve .`
Deploy: any static host (GitHub Pages, Netlify, Vercel). Publish directory is the repo root, no build command.
